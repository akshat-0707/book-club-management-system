# Online Book Club Management Platform (Page Turners)

A client-side web application designed to help book clubs coordinate reading selections, discussion meetings, member participation, and chapter discussion topics across books.

## Problem Statement & Objective
Book clubs often face challenges coordinating schedules and discussions across disparate messaging groups. They need a centralized system to coordinate reading selections, track discussion meetings, monitor member participation, and organize discussion topics across different books.

The **Online Book Club Management Platform** solves this by providing a unified web hub covering all core operational pillars:
1. **Book Selection:** Browse current reads, vote on upcoming books, and submit suggestions for future titles.
2. **Members Directory:** Display enrolled club members, join dates, and preferred reading genres.
3. **Reading Schedule:** Track chapter milestones and deadlines leading up to weekly meetings.
4. **Meetings & RSVP:** Coordinate upcoming meeting times and locations with interactive RSVP status updates.
5. **Discussion Topics & Comments:** Explore collapsible chapter prompts and post real-time reflections using DOM manipulation.
6. **Participation Tracking:** Monitor meeting attendance, comments posted, and books finished per member.

---

## Modules & Key Features

- **Home Dashboard:** Quick view of current club announcements, active reading title (*Harry Potter*), next scheduled meeting, and quick-navigation shortcuts.
- **Book Selection (`books.html`):** Interactive voting buttons for nominated titles (*Atomic Habits*, *Wings of Fire*, *The White Tiger*) and a validated book suggestion form with dynamic confirmation feedback.
- **Members (`members.html`):** Structured directory displaying member roles, joining dates, and reading preferences.
- **Reading Schedule (`schedule.html`):** Week-by-week reading breakdown for the selected book (*Harry Potter*).
- **Meetings (`meetings.html`):** Dynamic RSVP buttons that toggle state between "Join" and "Joined", alongside historical records of past meetings.
- **Discussions (`discussions.html`):** Collapsible accordion components for book discussion prompts and a live comment submission box that renders comments dynamically to the page feed.
- **Participation (`participation.html`):** Activity summary tracking meetings attended, comments posted, and total books completed.
- **Authentication (`login.html`):** Clean member login and logout interface.

## Technologies Used
- **HTML5:** Semantic document structuring (`<nav>`, `<section>`, `<article>`, `<table>`, `<form>`, `<input>`, `<button>`).
- **CSS3:** Custom layout styling, Flexbox navigation, CSS Grid cards, modern data tables, and media queries for responsiveness.
- **JavaScript (Vanilla JS):** DOM element manipulation, event listeners (`click`, `submit`), form handling, accordion toggle logic, and dynamic comment appending.
